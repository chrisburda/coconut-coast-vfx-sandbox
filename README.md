# Coconut Coast VFX Gym

Play the sandbox: https://chrisburda.github.io/coconut-coast-vfx-sandbox/

This repository contains the compiled sandbox and its game assets. Updates to main publish automatically through GitHub Pages.

Choose a power-up inside the preview, then use Preview or Drive & test. Drive with WASD / arrow keys, Shift to drift, and F to use the selected item. The on-screen controls work too.
